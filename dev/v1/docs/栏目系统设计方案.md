## 二、数据库设计

### 1. 栏目表 `category`

```sql
CREATE TABLE category (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    parent          INTEGER DEFAULT 0,           -- 父栏目ID（0=顶级）
    name            TEXT NOT NULL UNIQUE,        -- 栏目标识（英文，用于URL）
    title           TEXT NOT NULL,               -- 栏目名称
    
    -- 栏目类型
    type            INTEGER DEFAULT 0,           -- 0=列表 1=单页 2=链接 3=封面
    
    -- 模型绑定（type=0 列表栏目时有效）
    modelName       TEXT DEFAULT '',             -- 绑定模型名称（如 article）
    modelNs         TEXT DEFAULT '',             -- 绑定模型命名空间（如 cms）
    
    -- 外观配置
    icon            TEXT DEFAULT '',             -- 图标类名
    image           TEXT DEFAULT '',             -- 栏目缩略图
    banner          TEXT DEFAULT '',             -- 栏目Banner大图
    
    -- 内容（根据类型使用）
    link            TEXT DEFAULT '',             -- 外部链接（type=2）
    content         TEXT DEFAULT '',             -- 单页/封面内容（type=1,3）
    
    -- 模板配置（前台渲染用，预留）
    tplList         TEXT DEFAULT '',             -- 列表页模板
    tplDetail       TEXT DEFAULT '',             -- 详情页模板
    
    -- 访问控制（栏目级默认值）
    authLevel       INTEGER DEFAULT 0,           -- 默认访问级别 0=公开 1=登录 2=VIP 3=付费
    
    -- 显示控制
    sort            INTEGER DEFAULT 0,           -- 排序值（越小越靠前）
    visible         INTEGER DEFAULT 1,           -- 是否在导航显示
    status          INTEGER DEFAULT 1,           -- 状态：0=禁用 1=正常
    
    -- SEO配置
    seoTitle        TEXT DEFAULT '',
    seoKeywords     TEXT DEFAULT '',
    seoDesc         TEXT DEFAULT '',
    
    -- 时间戳
    createTime      INTEGER DEFAULT 0,
    updateTime      INTEGER DEFAULT 0,
    isDelete        INTEGER DEFAULT 0
);

-- 索引
CREATE INDEX idx_category_parent ON category(parent);
CREATE INDEX idx_category_name ON category(name);
CREATE INDEX idx_category_model ON category(modelName);
```

### 2. 栏目类型说明

| type | 类型 | 说明 | 模型绑定 | 前台展示 |
|------|------|------|----------|----------|
| 0 | 列表栏目 | 绑定内容模型 | ✅ 必选 | 内容分页列表 |
| 1 | 单页栏目 | 富文本内容 | ❌ | 单页内容（关于我们） |
| 2 | 外部链接 | 跳转URL | ❌ | 直接跳转 |
| 3 | 封面栏目 | 聚合子栏目 | ❌ | 子栏目导航+简介 |

## 三、模型系统改造

### 1. 新增系统字段：`categoryId`

在模型配置中增加栏目关联开关：

```json
"features": {
    "enableApi": true,
    "enableAdmin": true,
    "enableSubmit": false,
    "enableReply": false,
    "enableAccessControl": false,
    "enableCategory": true        // 🆕 启用栏目关联
}
```

当 `enableCategory = true` 时：
- 数据表自动添加 `categoryId` 字段
- 添加/编辑内容时显示栏目选择器
- 前台列表API支持 `?categoryId=xxx` 筛选

### 2. 系统字段清单（更新后）

| createTime | INTEGER | 创建时间 | 始终 |
| updateTime | INTEGER | 更新时间 | 始终 |
| isDelete | INTEGER | 软删除标记 | 始终 |
| authorType | INTEGER | 作者类型 | 始终 |

## 四、系统架构

```
栏目管理系统
├── 后台管理 (/admin/category/*)
│   ├── list     - 栏目树形列表
│   ├── get      - 获取栏目详情
│   ├── add      - 添加栏目
│   ├── save     - 保存栏目
│   ├── delete   - 删除栏目
│   └── sort     - 批量排序
│
├── 前台API (/api/v1/category/*)
│   ├── tree     - 获取完整栏目树
│   ├── nav      - 获取导航菜单（仅visible=1）
│   ├── get      - 获取栏目详情
│   ├── children - 获取子栏目
│   └── content  - 获取栏目内容（根据type智能返回）
│
└── 与模型系统集成
    ├── 内容表添加 categoryId 字段
    ├── 添加内容时选择所属栏目
    └── 列表筛选支持 categoryId
```

## 六、API设计

### 后台管理API

| API | 方法 | 说明 |
|-----|------|------|
| `/admin/category/list` | GET | 获取栏目树（含子栏目） |
| `/admin/category/get?id=xxx` | GET | 获取单个栏目 |
| `/admin/category/add` | POST | 添加栏目 |
| `/admin/category/save` | POST | 保存栏目 |
| `/admin/category/delete?id=xxx` | DELETE | 删除栏目 |
| `/admin/category/sort` | POST | 批量更新排序 |
| `/admin/category/models` | GET | 获取可绑定的模型列表 |

### 前台API

| API | 方法 | 说明 |
|-----|------|------|
| `/api/v1/category/tree` | GET | 完整栏目树 |
| `/api/v1/category/nav` | GET | 导航菜单（visible=1） |
| `/api/v1/category/get?id=xxx` | GET | 栏目详情 |
| `/api/v1/category/content?id=xxx` | GET | 智能获取栏目内容 |

### `/api/v1/category/content` 智能返回逻辑

```
if (type == 0) 列表栏目
    → 查询绑定模型的内容列表（自动加 categoryId 筛选）
    → 返回 {type:0, model:"article", list:[...], count:100}

if (type == 1) 单页栏目
    → 返回 {type:1, content:"富文本内容..."}

if (type == 2) 外部链接
    → 返回 {type:2, link:"https://..."}

if (type == 3) 封面栏目
    → 返回 {type:3, content:"封面介绍...", children:[子栏目列表]}
```
