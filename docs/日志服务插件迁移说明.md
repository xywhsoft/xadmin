# 日志服务插件迁移说明

## 定位

`xlogserver` 是从旧项目 `D:\git\xlogserver` 迁移到 xAdmin 插件系统的日志接收与查看插件。

当前迁移目标是优先承接旧业务日志，不改变旧外部投递接口的鉴权行为。

## 保留功能

- 服务管理：创建、编辑、软删除日志服务。
- 每服务独立数据库：每个 service 仍拥有独立 SQLite 数据库文件。
- 任务管理：每个服务下创建、编辑、软删除任务。
- 任务日志表：每个 task 使用独立 `log_<taskId>` 表保存日志。
- 日志写入：外部系统通过兼容接口写入日志。
- 日志查看：后台按任务查看日志，支持轮询刷新、暂停、手动刷新、清空。
- 日志裁剪：按插件配置保留最大日志行数。
- 菜单入口：插件只注册 `日志服务` 菜单分类和 `服务管理` 菜单项；具体服务从服务管理页面进入，不再为每个服务生成菜单项。

## 后台路由

插件主路由使用 xAdmin 插件命名空间：

- `GET /admin/view/plugin/xlogserver`
- `GET /admin/view/plugin/xlogserver/services/add`
- `GET /admin/view/plugin/xlogserver/services/edit?id=<serviceId>`
- `GET /admin/view/plugin/xlogserver/tasks?serviceId=<serviceId>`
- `GET /admin/view/plugin/xlogserver/tasks/add?serviceId=<serviceId>`
- `GET /admin/view/plugin/xlogserver/tasks/edit?serviceId=<serviceId>&id=<taskId>`
- `GET /admin/view/plugin/xlogserver/tasks/logs?serviceId=<serviceId>&taskId=<taskId>`
- `/admin/api/plugin/xlogserver/services`
- `/admin/api/plugin/xlogserver/tasks?serviceId=<serviceId>`
- `/admin/api/plugin/xlogserver/task/logs?serviceId=<serviceId>&taskId=<taskId>`

为兼容旧后台链接，同时注册以下受后台鉴权保护的旧路径别名：

- `/view/services`
- `/view/services/add`
- `/view/services/edit`
- `/view/services/tasks?id=<serviceId>`
- `/view/tasks/add?serviceId=<serviceId>`
- `/view/tasks/edit?serviceId=<serviceId>&id=<taskId>`
- `/view/tasks/logs?serviceId=<serviceId>&taskId=<taskId>`
- `/services`
- `/tasks?serviceId=<serviceId>`，也兼容 `/tasks?id=<serviceId>`
- `/task/logs?serviceId=<serviceId>&taskId=<taskId>`，也兼容 `/task/logs?id=<serviceId>&taskId=<taskId>`

## 外部兼容接口

以下接口保持无鉴权，用于承接旧业务：

- `POST /api/v1/log/push`
- `POST /api/v1/task/create`

`/api/v1/log/push` 请求体：

```json
{
  "service": 1,
  "task": 1,
  "class": "info",
  "text": "log text"
}
```

`/api/v1/task/create` 请求体：

```json
{
  "service": 1,
  "name": "task name",
  "desc": "optional description"
}
```

## 插件系统依赖

插件依赖 `XADMIN_GLOBAL_HOST_CONTEXT` 获取宿主上下文，尤其是：

- `plugin_root_path`
- `plugin_data_path`
- `plugin_private_db_path`
- `app_path`
- `main_db`

旧的分散注入槽位仍兼容保留，但新代码应优先使用 `XAdminHostContext`。

## 已知约束

- 外部 API 暂时保持无鉴权，后续如恢复公网业务，需要单独设计签名或 token 兼容层。
- 服务数据库文件软删除后保留，不随服务删除而物理删除。
- 任务软删除后日志表保留，不随任务删除而物理删除。
- 后台旧路径别名仅用于迁移兼容，新页面与菜单应使用 `/admin/view/plugin/xlogserver...` 命名空间。
