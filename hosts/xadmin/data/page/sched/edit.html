到达指定时间后仅执行一次。
适合固定频率的轮询、同步、清理类任务。
例如：`0 */5 * * * *` 表示每 5 分钟一次；`0 0 2 1 * * 2027` 表示 2027 年每月 1 日 02:00:00 执行。

超时后会终止当前任务进程，避免长期占用资源。并行上限仅在“允许并行执行”时生效，0 表示不限制。
用于 xAdmin 重启或暂停期间错过执行点时的恢复策略。
任务失败或超时后，会按延迟再次调度。当前仅对非并行模式生效。
自定义参数 JSON
保存为 JSON 文本。C 任务里可通过 `pTaskInfo->custom_json` 读取原文，通过 `pTaskInfo->custom_data` 读取解析后的结构。
任务代码
Shell 任务会在独立子进程中执行，标准输出和标准错误会写入执行日志。
C 任务只需要写一个裸函数 `int TaskProc(TaskInfo* pTaskInfo)`；模板会自动补齐运行入口和退出逻辑。
