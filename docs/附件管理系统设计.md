# 附件管理系统设计文档

## 一、概述

附件管理系统提供文件上传、访问控制、付费下载等功能，支持与内容模型关联或作为全局附件独立存在。

### 1.1 核心特性

- **安全存储**：附件存储于 `data/uploads` 目录，禁止直接访问，必须通过接口访问
- **防盗链**：支持 Referer 检测，可配置白名单域名（支持通配符）
- **访问控制**：支持公开、登录可见、付费下载三种模式
- **付费功能**：用户可设置附件价格，其他用户需购买后才能下载
- **存储统计**：提供总存储、按模型、按类型的统计功能
- **用户配额**：可限制每个用户的上传总量

## 五、访问控制流程

```
访问请求 /attachment/{xid}
    │
    ├── 查询附件记录
    │   └── 不存在 → 404
    │
    ├── 检查防盗链（allowHotlink=0 时）
    │   └── 验证 Referer
    │       ├── 无 Referer → 根据配置决定
    │       ├── 本站域名 → 通过
    │       ├── 白名单域名 → 通过
    │       └── 其他 → 403
    │
    ├── 检查访问类型
    │   ├── [0-公开] → 允许
    │   ├── [1-登录可见]
    │   │   └── 未登录 → 401
    │   └── [2-付费下载]
    │       ├── 上传者本人 → 允许
    │       ├── 未登录 → 401
    │       ├── 已购买 → 允许
    │       └── 未购买 → 402
    │
    └── 返回文件
        ├── 图片/文本/PDF/音视频 → inline
        └── 其他 → attachment (下载)
```

## 六、防盗链白名单实现

采用**双字典**方案，支持精确匹配和通配符：

### 6.1 数据结构

```c
Dict* G_HotlinkExact;    // 精确域名 {"example.com": 1}
Dict* G_HotlinkSuffix;   // 后缀域名 {".example.com": 1}
```

### 6.2 配置解析

```
example.com       → G_HotlinkExact["example.com"]
*.example.com     → G_HotlinkSuffix[".example.com"]
```

### 6.3 检测算法

```c
bool CheckHotlinkWhitelist(str sHost, size_t iLen) {
    // 1. 精确匹配 O(1)
    if (xrtDictGet(G_HotlinkExact, sHost, iLen))
        return TRUE;
    
    // 2. 后缀匹配 O(k)，k=域名层级数
    str p = sHost;
    while ((p = strchr(p, '.')) != NULL) {
        if (xrtDictGet(G_HotlinkSuffix, p, iLen - (p - sHost)))
            return TRUE;
        p++;
    }
    return FALSE;
}
```

**时间复杂度**：O(1) ~ O(k)，k通常为2-4

## 八、购买流程

```
用户请求购买
    │
    ├── 验证登录状态
    ├── 查询附件信息
    ├── 检查是否已购买 → 是 → 返回"已购买"
    ├── 检查余额 → 不足 → 返回"余额不足"
    │
    ├── 事务开始
    │   ├── 扣除买家余额
    │   ├── 计算卖家收入（扣除平台抽成）
    │   ├── 增加卖家余额
    │   ├── 插入购买记录
    │   ├── 更新附件销量
    │   └── 记录余额变动日志
    └── 事务提交
    
    └── 返回购买成功
```
