联网搜索

已登录会员通过统一 API 调用博查和 z.ai。密钥由服务端保管。

平台密钥

环境变量 BOCHA_API_KEY / ZAI_API_KEY 优先。留空保留原密钥，勾选删除后清除文件中保存的密钥。

访问规则与额度

在后台「插件管理 → 联网搜索代理 → 配置」设置默认平台、验证要求和额度。默认要求已验证手机，每会员 5 次/分钟、100 次/天，全站 10,000 次/天。

额度按实际转发尝试计数，上游失败也计入；不会自动重试或切换付费平台。每日额度在 UTC 零点重置。

客户端接口

支持会员 Bearer JWT，也支持同站 Cookie（POST 需 X-CSRF-Token）。

POST /api/v1/search
Authorization: Bearer <会员 access_token>
Content-Type: application/json

{"provider":"bocha","query":"联网搜索关键词","count":5}

GET /api/v1/search/providers 查看平台状态；GET /api/v1/search/usage 查看个人额度。z.ai 使用 search-prime，当前不提供日期筛选；博查支持 freshness。
