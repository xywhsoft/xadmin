插件生态

插件是 xadmin 的业务扩展单元。它拥有独立目录、路由、菜单、配置、静态资源和运行时生命周期。

插件目录规范

page / template

page 存放需要鉴权访问的后台页面，template 存放插件模板。

option / static

option 存放配置文件，static 通过 `/plugin-static/<xid>/...` 公开访问。

src / inc / lib

服务于 TCC 编译和第三方头文件、def 文件加载，保持插件代码边界清晰。

插件市场方向

插件商店、导入导出、版本和授权能力将围绕 xadmin 插件包展开。当前门户先提供入口和规范说明。
