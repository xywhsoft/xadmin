# 调试接口说明

本文档说明 xAdmin 系统的调试接口，用于跟踪和监控全局缓存数据。

> 所有接口需要登录鉴权，不记录访问日志。

---

## GET /trace

获取全局缓存概览。

**返回字段：**

| 字段 | 说明 |
|------|------|
| `data.installed` | 系统是否已安装 |
| `data.session.exists` | Session 缓存是否存在 |
| `data.session.count` | Session 数量 |
| `data.option.exists` | Option 配置缓存是否存在 |
| `data.option.count` | Option 命名空间数量 |
| `data.auth.roleAuth_exists` | 角色权限缓存是否存在 |
| `data.auth.roleAuth_count` | 角色权限项数量 |
| `data.auth.auth_exists` | 权限组缓存是否存在 |
| `data.auth.auth_count` | 权限组数量 |
| `data.auth.group_exists` | 权限分类缓存是否存在 |
| `data.auth.group_count` | 权限分类数量 |
| `data.auth.role_exists` | 角色列表缓存是否存在 |
| `data.auth.role_count` | 角色数量 |
| `data.route.exists` | 路由表是否存在 |
| `data.route.count` | 路由数量 |
| `data.database.connected` | 数据库是否已连接 |

---

## GET /trace/session

获取完整的 Session 缓存数据。

**返回字段：**

| 字段 | 说明 |
|------|------|
| `data` | Session 表，键为 SessionID，值为会话信息 |

---

## GET /trace/option

获取完整的 Option 配置缓存数据。

**返回字段：**

| 字段 | 说明 |
|------|------|
| `data` | 配置表，按 namespace 分组，每个 namespace 下为配置键值对 |

---

## GET /trace/auth

获取权限相关缓存数据。

**参数：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `type` | 数据类型：`all`/`roleAuth`/`auth`/`group`/`role` | `all` |

**返回字段：**

| 字段 | 说明 |
|------|------|
| `data.roleAuth` | 角色权限缓存，键为角色ID，值为权限ID数组 |
| `data.auth` | 权限组列表（前端渲染用） |
| `data.group` | 权限分类列表（前端渲染用） |
| `data.role` | 角色列表（前端渲染用） |

---

## GET /trace/route

获取路由表数据。

**返回字段：**

| 字段 | 说明 |
|------|------|
| `data` | 路由数组 |
| `data[].uri` | 路由 URI |
| `data[].log` | 是否记录访问日志 |
| `data[].auth` | 是否需要鉴权 |
| `data[].authId` | 关联的权限组 ID |
