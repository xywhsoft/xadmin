## 1. 附件管理

### attachment - 附件表

存储系统中所有上传的附件信息。

| 字段名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| xid | TEXT | - | **主键**，XID 唯一标识符 |
| filename | TEXT | - | 原始文件名 |
| ext | TEXT | - | 文件扩展名（如 jpg, pdf） |
| mime | TEXT | - | MIME 类型（如 image/jpeg） |
| size | INTEGER | 0 | 文件大小（字节） |
| path | TEXT | - | 存储路径（相对于 uploads 目录） |
| modelName | TEXT | '' | 关联模型名称（如 cms/article） |
| recordId | INTEGER | 0 | 关联记录 ID |
| uploaderId | INTEGER | 0 | 上传者 ID |
| uploaderType | INTEGER | 1 | 上传者类型：0=后台用户，1=前台用户 |
| allowHotlink | INTEGER | 1 | 是否允许外链：0=禁止，1=允许 |
| accessType | INTEGER | 0 | 访问类型：0=公开，1=登录可见，2=付费 |
| price | INTEGER | 0 | 价格（分），accessType=2 时有效 |
| priceType | INTEGER | 0 | 货币类型：0=余额 |
| salesCount | INTEGER | 0 | 销售次数 |
| downloadCount | INTEGER | 0 | 下载次数 |
| remark | TEXT | '' | 备注 |
| createTime | INTEGER | - | 创建时间（Unix 时间戳） |
| isDelete | INTEGER | 0 | 删除标记：0=正常，1=已删除 |

### attachmentOrder - 附件订单表

记录用户购买付费附件的订单。

| 字段名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| id | INTEGER | - | **主键**，自增 |
| attachmentXid | TEXT | - | 附件 XID |
| memberId | INTEGER | - | 购买者用户 ID |
| price | INTEGER | 0 | 支付金额（分） |
| priceType | INTEGER | 0 | 货币类型：0=余额 |

## 权限系统架构说明

### 双权限体系

系统采用前后台分离的双权限体系：

```
后台权限体系                          前台权限体系
─────────────                        ─────────────
user (后台用户)                       member (前台用户)
  ↓                                    ↓
role (后台角色)                       memberGroup (前台用户组)
  ↓                                    ↓
authList → auth (权限分组)            authList → memberAuth (权限分组)
             ↓                                     ↓
           authGroup (权限分类)                  memberAuthGroup (权限分类)
             ↓                                     ↓
           uris (isBackend=1)                    uris (isBackend=0)
```

### 权限判断流程

1. **后台访问**：
   - 获取用户角色 → 获取 authList → 获取关联的 auth → 查找 URI 是否在权限范围内

2. **前台访问**：
   - 获取用户组 → 获取 authList → 获取关联的 memberAuth → 查找 URI 是否在权限范围内

3. **authLevel 越权检查**：
   - 低权限用户不能编辑/删除高权限用户
   - 用于防止平级或下级用户越权操作

## 时间字段说明

所有 `createTime`、`updateTime` 字段使用 **Unix 时间戳**（秒级精度）存储。

前端显示时需要进行格式转换，推荐使用 `layui.util.toDateString()` 进行格式化。

## 软删除机制

带有 `isDelete` 字段的表支持软删除：
- `isDelete = 0`：正常记录
- `isDelete = 1`：已删除记录

查询时默认过滤已删除记录，后台可查看回收站内容。
