XForm Template Block Demo
This page is rendered from the template cache. The {{#form}} block below is parsed at template compile time, and the inner JSON is converted into static HTML before runtime rendering.
Demo: Load Existing Form JSON
This block references demo_form.json and uses its persisted demoData.
{{#form}} { "source": "form", "file": "demo_form.json" } {{#end}}
If you edit this template file and click "模板缓存重新加载", the precompiled block HTML will update without needing to rebuild the whole app.
Compile-Time Behavior
Runtime rendering only outputs the pre-generated HTML. It does not re-parse the JSON or rebuild this form block for every request.
