```c
    bool bEnableSubmit;         // 启用前台投稿
```

### 2.2 条件块处理

#### Model_ProcessCondBlock (行147-231)

处理模板中的 IF/ELSE/ENDIF 条件块：

```c
str Model_ProcessCondBlock(str sCode, str sIfTag, str sElseTag, str sEndifTag, bool bCondition)
```

**参数说明**：
- `sCode`: 源代码
- `sIfTag`: IF 标签，如 `{{#IF_ENABLE_ACCESS_CONTROL}}`
- `sElseTag`: ELSE 标签，如 `{{#ELSE}}`（可为 NULL）
- `sEndifTag`: ENDIF 标签
- `bCondition`: 条件值

**处理逻辑**：
1. 查找 IF 标签位置
2. 查找对应的 ENDIF 标签
3. 检查中间是否有 ELSE 标签
4. 根据条件值保留对应代码块，删除另一块


#### Model_GenerateCode (行774-1127)

主代码生成函数：

```c
bool Model_GenerateCode(ModelInstance* pModel)
```

**生成流程**：
1. 读取模板文件 `model_code.tpl`
2. 构建字段相关字符串（名称列表、占位符、SET子句等）
3. 遍历字段生成各类代码片段
4. 替换模板变量（`{{MODEL_NAME}}`, `{{TABLE_NAME}}` 等）
5. 处理条件块（IF/ELSE/ENDIF）
6. 保存到 `script/model/{name}/code.h`

**模板变量列表**：

| 变量 | 说明 |
|-----|------|
| `{{MODEL_NAME}}` | 模型名称 |
| `{{MODEL_TITLE}}` | 模型标题 |
| `{{TABLE_NAME}}` | 数据表名 |
| `{{DRAFT_TABLE_NAME}}` | 草稿表名 |
| `{{NAMESPACE_PATH}}` | 命名空间路径（带/） |
| `{{GEN_TIME}}` | 生成时间 |
| `{{FIELD_NAMES}}` | 字段名列表 |
| `{{FIELD_PLACEHOLDERS}}` | SQL占位符 |
| `{{FIELD_UPDATE_SET}}` | UPDATE SET子句 |
| `{{FIELD_READ_CODE}}` | 列表读取代码 |
| `{{FIELD_READ_CODE_GET}}` | 详情读取代码 |
| `{{FIELD_BIND_ADD_CODE}}` | 添加绑定代码 |
| `{{FIELD_BIND_UPDATE_CODE}}` | 更新绑定代码 |
| `{{API_AUTH_LEVEL}}` | API权限级别 |
| `{{ADMIN_AUTH_ID}}` | 后台权限组ID |

## 3. model_code.tpl - 代码模板

### 3.1 模板结构

```c
// 头部注释和包含
#include <xsbase.h>

// 全局变量声明
XDO_Connect G_DB;

// 预编译语句声明
sqlite3_stmt* stmt_{{MODEL_NAME}}_all;
sqlite3_stmt* stmt_{{MODEL_NAME}}_get;
// ...

// 初始化函数
void Model_{{MODEL_NAME}}_InitStmt()

// 清理函数
void Model_{{MODEL_NAME}}_CleanupStmt()

// API处理函数
{{#IF_ENABLE_API}}
void Request_Api_{{MODEL_NAME}}_List(...)
void Request_Api_{{MODEL_NAME}}_Get(...)
{{#ENDIF_ENABLE_API}}

// 后台管理函数
{{#IF_ENABLE_ADMIN}}
void Request_Admin_{{MODEL_NAME}}_List(...)
void Request_Admin_{{MODEL_NAME}}_Get(...)
void Request_Admin_{{MODEL_NAME}}_Add(...)
void Request_Admin_{{MODEL_NAME}}_Put(...)
void Request_Admin_{{MODEL_NAME}}_Del(...)
{{#ENDIF_ENABLE_ADMIN}}

// 路由注册函数
void Model_{{MODEL_NAME}}_RegisterRoutes()

// 入口函数
void Model_Init()
void Model_Cleanup()
```

### 3.2 条件块语法

**简单条件块**：
```c
{{#IF_ENABLE_API}}
// 仅当 enableApi=true 时包含
{{#ENDIF_ENABLE_API}}
```

**带 ELSE 的条件块**：
```c
{{#IF_ENABLE_ACCESS_CONTROL}}
    // 启用访问控制时的 SQL
    "SELECT id, ..., accessLevel, accessPrice, ..."
{{#ELSE}}
    // 不启用访问控制时的 SQL
    "SELECT id, ..., authorType, authorId, ..."
{{#ENDIF_ENABLE_ACCESS_CONTROL}}
```

**支持的条件标签**：
- `{{#IF_ENABLE_API}}` / `{{#ENDIF_ENABLE_API}}`
- `{{#IF_ENABLE_ADMIN}}` / `{{#ENDIF_ENABLE_ADMIN}}`
- `{{#IF_ENABLE_SUBMIT}}` / `{{#ENDIF_ENABLE_SUBMIT}}`
- `{{#IF_ENABLE_REPLY}}` / `{{#ENDIF_ENABLE_REPLY}}`
- `{{#IF_ENABLE_ACCESS_CONTROL}}` / `{{#ELSE}}` / `{{#ENDIF_ENABLE_ACCESS_CONTROL}}`
- `{{#IF_ENABLE_DRAFT}}` / `{{#ENDIF_ENABLE_DRAFT}}`

## 5. 运行时编译流程

### 5.1 TCC 编译过程

```c
// 1. 创建 TCC 状态机
TCCState* pTcc = tcc_new();

// 2. 设置输出类型为内存
tcc_set_output_type(pTcc, TCC_OUTPUT_MEMORY);

// 3. 添加包含路径
tcc_add_include_path(pTcc, includePath);

// 4. 编译代码文件
tcc_add_file(pTcc, codePath);

// 5. 添加符号（让模型代码能调用主程序函数）
tcc_add_symbol(pTcc, "Model_AddRoute", Model_AddRoute);
tcc_add_symbol(pTcc, "Model_RemoveRoute", Model_RemoveRoute);
// ...

// 6. 重定位（链接）
tcc_relocate(pTcc, TCC_RELOCATE_AUTO);

// 7. 获取并调用初始化函数
typedef void (*ModelInitProc)();
ModelInitProc procInit = tcc_get_symbol(pTcc, "Model_Init");
procInit();
```

## 7. 常见问题排查

### 7.1 TCC 编译错误

**错误信息格式**：
```
[TCC] Loading model: {name}
{file}:{line}: error: {message}
```

**常见原因**：
1. 模板语法错误 - 检查条件块是否匹配
2. 类型不匹配 - `str` (unsigned char*) 与 `char*` 需显式转换
3. 函数参数错误 - 检查生成的代码中占位符替换是否正确

### 7.2 路由未生效

**排查步骤**：
1. 检查模型是否已启用 (`status.enabled = true`)
2. 检查控制台输出是否有 `[Model] Add route: xxx`
3. 检查权限配置是否正确

### 7.3 字段不显示

**排查步骤**：
1. 检查字段配置中 `showInList` 是否为 `true`
2. 检查字段名称是否与系统字段冲突
3. 检查生成的 SQL 语句是否包含该字段
