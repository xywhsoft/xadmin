# 身份数据库迁移

身份迁移位于 `src/storage/identity_migration.c`，SQL 随应用编译，避免单文件/VFS 部署遗漏外部 SQL。`xadmin_migration` 按组件、版本登记 SHA256；不占用旧时间迁移的 `PRAGMA user_version`。已发布的 SQL 不原地修改，后续结构使用新版本。

首次迁移先检查所有历史账号，包括软删除账号。账号采用 ASCII 字母、数字、点、下划线、连字符，3–64 字节，至少含一个字母，大小写不敏感。历史格式或大小写冲突只报告会员 ID，停止启动，由站点管理员显式修复。

通过检查后，以 SQLite backup API 创建 `db/identity-before-v1.db`，再事务迁移。备份已存在但迁移尚未登记时停止，避免覆盖或误用失败备份。成功后重启不重复迁移；校验和或未来版本不符时拒绝启动。

旧手机、邮箱原文保留，验证状态为零，不参与登录或唯一绑定。邮箱本地部分区分大小写，域名不区分；不进行供应商特定转换。手机号使用 E.164，未配置国家码时只接受国际形式；本地号码以零开头时要求显式国际形式，不猜测国家冠码。

用户名、已验证联系方式、外部身份在软删除后仍保留归属，禁止重新注册后取得旧身份。未验证历史联系方式允许重复，用户完成专用绑定流程后才进入唯一约束。
