重新加载

模板缓存重新加载

重新扫描并预编译 data/template 下的所有模板文件，适合模板调试和热更新。

接口：/admin/tool/reload/template

当前 Host 重新加载

仅重新加载当前 Host 的脚本上下文，影响范围最小，适合常规脚本热更新。

接口：/admin/tool/reload/host

当前服务重新加载

重新加载当前服务下的全部 Host，适合一次性刷新当前服务的脚本宿主状态。

接口：/admin/tool/reload/server

xs 整体重新加载

遍历当前进程中的全部服务并逐个 reload，适合全局同步变更后统一刷新。

接口：/admin/tool/reload/xs
